# Дизайн — поточний стан (текстовий знімок)

Джерело правди — клікабельний макет (Claude Artifact, Design canvas):
https://claude.ai/artifact/U9zexMtARry73jthp6tWMg
Назва канви: «Fines+ дашборд v2 — фінальний дизайн».

Цей файл — короткий знімок того, що на канві, щоб не відкривати її заради
самого лише списку екранів. Оновлюється окремим таском (CLAUDE.md →
«Робочі документи»), не автоматично при кожній зміні канви.

Востаннє звірено: 2026-09-21.

## Екрани (14, у групах канви)

**Перший запуск** — Onboarding, Registration (Реєстрація/Вхід), Subscription (Передплата)

**Основний потік** — Dashboard (Дашборд), FuelSheet/ServiceSheet/InsuranceSheet/MoreSheet
(bottom sheets: Заправка/ТО/Страхування/Ще), Garage (Гараж), Fines (Штрафи),
Reminders (Нагадування), Settings (Налаштування)

**Стан «штрафів немає»** — DashboardNoFines, FinesEmpty — окремі екрани для
випадку, коли в обраної машини немає штрафів (щоб не токсили порожні/умовні
стани на основних макетах)

## Формат

Кожен екран — окремий `.dc.html` артборд на канві (не Figma-файл).
Експортований PDF (усі 14 екранів, по одному на сторінку) лежить тут же:
`docs/Fines+ дашборд v2 — фінальний дизайн.pdf` — той самий файл відкривається
і в Figma (File → Import), кожна сторінка стає окремим фреймом.
